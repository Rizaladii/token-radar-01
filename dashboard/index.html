How the value is built

Every implied value follows from the snapshot's own figures. No protocol name is ever special-cased: the same function scores every row.

implied = TVL × sectorMultiple × growthMult × maturityMult × breadthMult

How to farm a row

Every row carries six steps: a fresh wallet, the category's core action with a concrete capital size, one qualifying action a week, a hold of 30–60 days, a check of the protocol's own points page, and a farm log. Each step states what it costs and how long it takes. Never pay to claim, and never follow a claim link from a chat or an ad.

What the board is not

It does not predict whether or when a protocol issues a token. It values the protocol as if its record stayed as it is, on the day the snapshot was taken.
